Release replay environment (25 November 2026, macOS arm64 host)
Interpreters (printed inside the run, not assumed):
- Scripts without third-party imports (coefficients, diameter5, graph_check, continuum_check, calibration_replay):
  requested as `uv run --no-project --python 3.12 python3`; on this host a `python3` shim resolves that to
  CPython 3.14.7 (/opt/homebrew/opt/python@3.14/bin/python3.14).
- Scripts run with pinned packages (`uv run --no-project --python 3.12 --with ...`: forest_replay, calibration_certificate,
  claims_check, rigidity_onset): uv built an ephemeral environment on CPython 3.12.11 with numpy 2.3.5, sympy 1.14.0 and
  mpmath 1.3.0 (versions printed inside the run).
Packages: requirements.txt pins numpy==2.3.5, sympy==1.14.0, mpmath==1.3.0. The other scripts use the standard library.
Working directory: the package root. Flags: python3 -I -B -O for every command; PYTHONDONTWRITEBYTECODE=1.
GitHub CI: ubuntu-latest, actions/setup-python 3.12, pip install -r requirements.txt; the nine fast scripts run under
python3 -I -B -O on every push (blocking); the rigidity scan (about 35 minutes) runs only on manual request and does not
block.
Cross-platform comparison (declared before tagging; same policy in CI, README.md, REPLAY_RECEIPT.md and
ci/compare_outputs.py):
- Verdicts are exact: integer and rational arithmetic (coefficients, diameter5, graph_check, forest_replay,
  rigidity_onset), exact sympy (calibration_certificate) and fixed-precision decimal output; continuum_check and
  claims_check also print double-precision diagnostics, and calibration_replay is a floating-point sanity scan over
  66,049 pairs.
- Each fresh output must have the same lines as the recorded results/ file, with every non-decimal token (words,
  integers, fractions, PASS, "ALL CHECKS PASSED") equal exactly.
- Printed decimal numbers (tokens with a decimal point or exponent) must agree within relative 1e-12 or absolute 1e-12.
- No output prints an interpreter or platform version, so no field is excluded.
On the release platform every output was byte-identical to the recorded file.
